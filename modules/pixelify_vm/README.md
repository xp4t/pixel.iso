This is a custom Magisk module for Android-x86 virtual machines, not the
upstream Kingsman44/Pixelify module. It sets the original 2016 Google Pixel
(sailfish) product identity. Disable it in Magisk and reboot to revert.

The kernel, drivers, CPU ABI, Android release/API, security patch level,
fingerprint and signing keys remain those of Android-x86. This does not
turn an x86 VM into ARM hardware, provide Pixel-exclusive hardware, certify
the VM, or guarantee Google service entitlements or device attestation.
